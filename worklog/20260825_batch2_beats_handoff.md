# バッチ2 引き渡し — 4ビート構成（2026-08-25）

Mac側パイプライン用。`scripts/video_shorts/short-XX.json` と
`outputs/video/short-XX/narration/*.txt` の形式に合わせてある。

既存9本と同じ4区分:
1. `01_hook.txt` — Hook
2. `02_bunkai.txt` — 問題の分解・理由
3. `03_naze.txt` — 解決方法
4. `04_cta.txt` — CTA／今日やること

各ビートは話速1.0で約12秒（およそ75〜85文字）を狙っている。合計約48秒。
既存9本の実測は46〜53秒なので同レンジ。

## 投稿設計の変更（実測にもとづく）

当初は1日1本を提案していたが、**集中投稿に変更する**。

| 投稿の出し方 | 結果 |
|---|---|
| 8/12〜8/13に7本を集中投稿 | 45〜1,851再生（当たり3本が982以上） |
| 8/17に単発 | 324再生 |
| 8/23に単発（10日空け） | **339再生で頭打ち、登録0、VPH半減** |

配信が乗るかどうかは、投稿の密度に相関している可能性が高い。
**5本を2日に分けて集中投下する**（8/12〜8/13の再現）。

推奨: 1日目に3本、2日目に2本。同日内は30分〜1時間空ける。

## 全5本共通のCTA方針

実測で完走率56%・登録率0.017%（5,987再生で1人）。最後まで見られているのに
登録されていないため、CTAの位置ではなく**登録する理由**が欠けている。

`04_cta.txt` は「登録してください」ではなく、**次に何が届くかを固有名で予告する**形に
統一した。予告は下記の投稿順に連動しているので、順番を変えるなら予告文も直すこと。

# short-12 — 手数料の足し算

**接続先ロング: `SjOcshMYLxE`** / LP `ec-tips-08`

### 01_hook.txt
```

```

### 02_bunkai.txt
```

### 03_naze.txt
```
正しくは割り算です。二千三百を〇・九で割って、およそ二千五百五十六円。二千六百円でようやくとんとん。利益を三割乗せるなら、およそ三千三百円です。
```

```
このチャンネルは、一人でネットショップを回す人が決めるだけで終わることを、一本に一つずつ出しています。次は、インスタのプロフィール導線の話です。
