## 判断の変更

これまでCTAの位置と文言を検証対象にしてきたが、**優先度を下げる**。

視聴者の83.8%が冒頭で去っている。CTAをどこに置いても、届く母数は16.2%しかない。
高評価0.07%・登録0という結果は、CTAの問題ではなく**入口で84%を失っていること**の帰結。

**バッチ3のCTA設計（30%地点のテロップ）は保留する。** 先にスワイプ率を下げる。

なお8/24の高評価率を0.16%と報告したが、これは1日だけの値だった。
28日通算では0.11%、バッチ2に限れば0.07%。訂正する。

`worklog/20260821_shorts_batch2_scripts.md` に記録した元の仕様は
**「背景：黒 / アクセント：コーラルレッド / 大見出し：92px」**だった。現行はこれから外れている。

ショートのフィードでは0.5秒以内に自分に関係があるかを判断される。
黒背景＋大きな白文字は一瞬で読めるが、写真背景＋小カードは
視線が写真に取られ、文字を探してから読むことになる。読む前にスワイプされる。

音声では「損だけ言い、正解は第3ビートまで伏せる」を徹底したのに、
**画面は0.5秒で答えを渡している。** 音声で作った引きを映像が打ち消している。

これは設計漏れ。`01_hook.txt` は直したが、`short-XX.json` の表示テキストを
同じ原則で点検していなかった。「正解」「手順」というバッジ自体が答えの予告になっている。

# 冒頭3秒の仕様

## 1. 背景

- **黒（#000）の単色**。写真・イラストを敷かない
- 写真を使うのは第2ビート以降

## 2. 文字

- 第1フレームの見出しは **92px以上**、白
- **20文字以内**。0.5秒で読み切れること
- 画面幅の8割を使う

## 3. 第1フレームに書く内容

**問題だけを書く。答え・手順・正解を書かない。**

| 書く | 書かない |
|---|---|
| 何が欠けているか | 欠けているものの中身 |
| 何を損しているか | 損を止める方法 |
| 誰に当てはまるか | 当てはまった後の対処 |

## 4. バッジ

答えの予告になる語を使わない。

| 使わない | 使う |
|---|---|
| 正解 / 手順 / 診断 | 盲点 / 損 / 確認 / よくある |

## 5. 書き換え例（バッチ2の実物）

**手数料**
- 現行: 「正解 / 2,300 ÷ 0.9 ≒ 2,556円 / 利益3割なら約3,300円」
- 修正: 「**損** / 売れるほど手元が減る / 2,300円 + 1割 = 2,530円で売っている人」

**青色申告**
- 現行: 「手順 / 出す紙は2枚だけ / 同じ日・同じ窓口・1か月以内」
- 修正: 「**損** / 罰金はない。ただし戻せない / 出していないと使えないものがある」

**インスタ**
- 現行: 「診断 / 一番多いのは3段目「リンク」/ 他人になったつもりで5分たどる」
- 修正: 「**盲点** / フォロワー1万人でも買われない / 切れているのは4つのうち1つ」

いずれも既存動画の作り直しではなく、**今後の新規動画に適用する**。
