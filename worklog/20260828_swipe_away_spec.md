# 冒頭3秒の仕様

## 1. 背景 ← **この項は失効。従ってはいけない**

- ~~**黒（#000）の単色**。写真・イラストを敷かない~~
- ~~写真を使うのは第2ビート以降~~

**正しくは逆。** 商品写真を主役にする（`publish_check.py` が強制、実測67.11%）。
画像は `image_pipeline.py` で生成し、出所を `ASSETS.md` に残す。

## 2. 文字

- 第1フレームの見出しは **92px以上**、白
- **20文字以内**。0.5秒で読み切れること
- 画面幅の8割を使う

## 3. 第1フレームに書く内容

**問題だけを書く。答え・手順・正解を書かない。**

| 書く | 書かない |
|---|---|
| 何が欠けているか | 欠けているものの中身 |
| 何を損しているか | 損を止める方法 |
| 誰に当てはまるか | 当てはまった後の対処 |

## 4. バッジ

答えの予告になる語を使わない。

| 使わない | 使う |
|---|---|
| 正解 / 手順 / 診断 | 盲点 / 損 / 確認 / よくある |

## 5. 書き換え例（バッチ2の実物）

**手数料**
- 現行: 「正解 / 2,300 ÷ 0.9 ≒ 2,556円 / 利益3割なら約3,300円」
- 修正: 「**損** / 売れるほど手元が減る / 2,300円 + 1割 = 2,530円で売っている人」

**青色申告**
- 現行: 「手順 / 出す紙は2枚だけ / 同じ日・同じ窓口・1か月以内」
- 修正: 「**損** / 罰金はない。ただし戻せない / 出していないと使えないものがある」

**インスタ**
- 現行: 「診断 / 一番多いのは3段目「リンク」/ 他人になったつもりで5分たどる」
- 修正: 「**盲点** / フォロワー1万人でも買われない / 切れているのは4つのうち1つ」

いずれも既存動画の作り直しではなく、**今後の新規動画に適用する**。
